# costo-plan

Código del modelo de costos plan (cascadeo) en Databricks / PySpark.

Aquí se guardan las celdas y módulos del notebook para llevar la traza de sus versiones.

## Convenciones
- Un archivo por celda o módulo, con prefijo numérico (`01_...`, `02_...`) según el orden en el notebook.
- Cada cambio se guarda con un commit: `costo-plan: qué cambió y por qué`.
- No subir claves, tokens ni datos reales.
