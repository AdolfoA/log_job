# Proyectos

Cada subcarpeta es un proyecto independiente de la bitácora (por ejemplo `costo-plan/`).
La pestaña **Código** de la bitácora lista estas carpetas y muestra cada archivo con su historial de versiones.

## Cómo agregar un proyecto
1. Crea una carpeta nueva dentro de `proyectos/` (minúsculas y guiones: `costo-plan`, `modelo-agua`).
2. Sube dentro los archivos de código (.py, .sql, .md, …).
3. Cada cambio se guarda con un commit; así la página puede mostrar las versiones y qué cambió.

## Reglas
- El repo es público: no subas claves, tokens, cadenas de conexión ni datos reales de la empresa.
- Mensajes de commit sugeridos: `costo-plan: qué cambió y por qué`.
